# assets/

Organize by module, mirroring the block-module abstraction in `../docs/design/game-prototype.md` (one folder per module, sized to its grid footprint), not by raw asset type. `../../Version_0/assets/` has the previous prototype's art (per-mechanism folders like `heater/`, `press/`, `centrifuge/`, `indicators/`, `containers/`) — treat it as source material to restructure and restyle into this new form, not something to copy over as-is.

Start with the wall-1 loadout only (Press and Pressure Tank, Centrifuge, Control Console — see `../CLAUDE.md`) rather than migrating every module up front.
